# Simple Interest Calculator

This is the final project for the *IBM Getting Started with Git and GitHub* course. It demonstrates basic version control skills including repository initialization, branch management, and shell scripting.

## Project Description

The purpose of this project is to provide a simple, automated tool for calculating the total interest earned or charged on a loan or investment over a specific period. It is designed to help users quickly determine financial growth based on a fixed interest rate.

*Files Included:*
* simple-interest.sh: The main script to calculate interest.
* CONTRIBUTING.md: Guidelines for contributing to this project.
* LICENSE: The Apache License 2.0.

## The Simple Interest Formula

This calculator uses the standard formula for Simple Interest:

$$\text{Simple Interest} = P \times R \times T$$

Where:
* *P* = Principal Amount (The initial sum of money)
* *R* = Annual Interest Rate (The percentage rate per year, entered as a decimal or percentage)
* *T* = Time Period (The duration in years)

### Calculation Example
If you want to calculate the interest for a *$1,000* principal at a *5%* annual interest rate for *3 years*:

1.  *Principal (P):* 1000
2.  *Rate (R):* 0.05 (which is 5% divided by 100)
3.  *Time (T):* 3

*Calculation:*
$$1000 \times 0.05 \times 3 = 150$$

*Output:*
The Simple Interest is *$150*.

## How to Use

To use the calculator, follow these steps:

1.  Ensure you have a bash terminal open.
2.  Run the script simple-interest.sh by entering the following command:
    bash
    bash simple-interest.sh
    
3.  When prompted, input the values for Principal, Rate, and Time.
